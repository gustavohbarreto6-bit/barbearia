O Sistema de Gestão para Barbearia é uma aplicação desenvolvida com o objetivo de facilitar a organização e o gerenciamento dos serviços de uma barbearia. O sistema permite cadastrar clientes, agendar horários e registrar os serviços realizados e seus respectivos pagamentos, contribuindo para um atendimento mais organizado e eficiente.

🎯 Objetivo

Desenvolver uma solução digital para auxiliar no controle das atividades diárias de uma barbearia, reduzindo a necessidade de registros manuais e facilitando o acesso às informações.

⚙️ Requisitos Funcionais

RF01 — Cadastro de Clientes

Permitir o cadastro de clientes, armazenando informações como nome, telefone e outros dados necessários para identificação.

RF02 — Agendamento de Horários

Permitir o agendamento de horários para os clientes, registrando a data, o horário e o serviço desejado.

RF03 — Registro de Serviços e Pagamentos

Permitir registrar os serviços realizados, seus respectivos valores e os pagamentos efetuados pelos clientes.

🛠️ Tecnologias Utilizadas

As tecnologias serão definidas de acordo com os requisitos do projeto. Entre as possibilidades estão:

HTML5 — estrutura da aplicação.

CSS3 — estilização e organização visual.

JavaScript — funcionalidades e interatividade.

Node.js — desenvolvimento do servidor.

SQLite — armazenamento e gerenciamento dos dados.
